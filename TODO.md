## Осталось: V-гравировка вывесок и гравировка картинки

### 1. V-гравировка
**Зачем:** объёмные буквы и вывески V-битой — одна из самых востребованных функций для декоративных работ.

**Что нужно:**
- Тип инструмента `V-bit`: угол при вершине (15–120°), диаметр кончика, максимальная глубина.
- Глубина реза зависит от ширины штриха: чем шире буква, тем глубже проход.
- Стратегия: несколько контурных проходов с уменьшением ширины (offset) и увеличением глубины; для широких букв — медиальная ось (skeleton).
- Разделение «по центру» и «с полкой» (flat depth).
- UI: режим «V-гравировка» для текста/контуров, угол, максимальная глубина, плоское дно.
- Предпросмотр: цвет по глубине, проверка лимита Z.

**Точки входа:**
- `elementGeometry` / новый `vCarveMoves()` в `buildToolpaths` (`src/core.js`).
- Поля в `ELEMENT_TYPES` и панель параметров (`src/ui.js`, `src/body.html`).
- `sceneChecks`: предупреждать, если угол/глубина не помещаются в поле.
- Тесты: глубина растёт к центру, нет резов ниже лимита Z, траектории внутри контура.

### 2. Гравировка картинки
**Зачем:** портреты, логотипы и фото на дереве/металле.

**Что нужно:**
- Загрузка PNG/JPEG через `<input type="file">` + canvas (без сервера).
- Перевод в оттенки серого, порог или дизеринг (Floyd–Steinberg / Atkinson).
- Два режима: точки (сверление/гравировка точками) и строки (растровая гравировка).
- Настройки: размер по X/Y, разрешение (точек на мм), порог, инверсия, глубина, шаг строки, скорость.
- Предпросмотр исходника и траектории; оценка количества точек/времени; предупреждение о размере файла.
- Сохранение картинки в проект невозможно в localStorage (большой размер) — хранить только настройки и имя файла.

**Точки входа:**
- Новый модуль `imageToMoves()` в `src/core.js` (canvas → ImageData → массив проходов).
- Новая вкладка/секция «Картинка» (`src/body.html`, `src/ui.js`).
- `movesBBox`, `drawPreview`, `estimateMoves` уже поддерживают произвольные `line/rapid/dot`.
- Тесты: детерминированный дизеринг (фиксированный seed), число точек, границы поля, лимит Z.

## Напоминания по архитектуре
- Всё ядро — чистые функции в `src/core.js`, UI не должен содержать геометрию.
- Общие параметры — `readParams()`; проект — `captureProject()` / `restoreProject()`; инструменты — `state.tools` + `normalizeTools()`.
- Новые поля элемента добавлять в `ELEMENT_TYPES`; поля постпроцессора — в `PROJECT_FIELDS` и `MAIN_IDS`.
- Высоты элемента — `el.depth`, `el.zProfile`, `el.z1/z2/zSteps`; синхронизировать в `templateScene`, `addElement`, `normalizeScene`, `captureProject/restoreProject`.
- Параметрика — `state.paramVars/paramMode/paramValues`, ядро `paramEval`, `PARAM_MODES`, `buildParametric`; UI — `renderParamUI`.
- После изменений: `node build.mjs`, `node test/core.test.mjs`, `node test/ui.test.mjs`, `node test/audit.mjs`, `node test/autosave.test.mjs`.
