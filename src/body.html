Структура программы

              

                
%; начало файла

                
O0001; номер программы

                
(комментарий); в скобках

                
G21 G90 G17 G94; мм, абсолют, XY, мм/мин

                
M3 S12000; шпиндель

                
G0 X0 Y0 Z5; безопасная позиция

                
... рабочая часть ...; траектории и циклы

G0 X0 Y0; возврат

% и O-номер — для Fanuc/LinuxCNC; Mach3 понимает %; GRBL работает без них. Комментарии — в скобках: (чистовая). Точка с запятой в кадре допустима не на всех стойках, поэтому генератор использует скобки.

Переменные — вещественные числа. Деление на ноль и корень из отрицательного дают аварию стойки.

            


            

              
Арифметика и функции

              
+ − * / и MOD (остаток). Скобки задают порядок действий, функции имеют приоритет.

              
#1 = 17 MOD 5           (2)
#2 = (10 + 2) * 3       (36)
#3 = #2 / 4             (9)

              

                
ФункцияСинтаксисРезультатПример

                
SINSIN[#1]Синус, угол в градусахSIN[30] = 0.5

                
COSCOS[#1]КосинусCOS[60] = 0.5

                
TANTAN[#1]ТангенсTAN[45] = 1

                
ASINASIN[#1]Угол по синусу, градусыASIN[0.5] = 30

                
ACOSACOS[#1]Угол по косинусуACOS[0.5] = 60

                
ATANATAN[#1]/[#2]Угол по Y/X с квадрантомATAN[1]/[1] = 45

                
ABSABS[#1]МодульABS[-5] = 5

                
SQRTSQRT[#1]Квадратный кореньSQRT[25] = 5

                
ROUNDROUND[#1]Округление до целогоROUND[2.6] = 3

                
FIXFIX[#1]Отбрасывание дробной частиFIX[-2.7] = -2

                
FUPFUP[#1]Округление вверхFUP[2.1] = 3

                
LNLN[#1]Натуральный логарифмLN[2.718] ≈ 1

                
EXPEXP[#1]e в степениEXP[1] ≈ 2.718

              

              
Аргумент функции обязательно в квадратных скобках: SIN[#1], а не SIN#1. Углы — в градусах (Fanuc, Haas, LinuxCNC).

            


            

              
Сравнения и логика

              

                
ОператорСмыслПример

                
EQравно (=)[#1 EQ 0]

                
NEне равно (≠)[#1 NE #2]

                
GTбольше (>)[#1 GT 10]

                
LTменьше (<)[#1 LT 10]

                
GEбольше или равно (≥)[#1 GE 0]

                
LEменьше или равно (≤)[#1 LE 5]

                
ANDлогическое И[#1 GT 0 AND #1 LT 10]

                
ORлогическое ИЛИ[#1 EQ 0 OR #2 EQ 0]

                
XORисключающее ИЛИ[#1 XOR #2]

              

              
Отдельного NOT нет: «не равно нулю» записывают как [#1 NE 0]. Условие всегда в квадратных скобках.

            


            

              
Переходы и циклы

              
Условный переход

              
IF [#100 LT 0] GOTO 200
IF [#1 EQ 0] GOTO 900
GOTO 300
N100 (продолжение)
N200 (аварийный выход)

              
Цикл WHILE

              
#1 = 0
WHILE [#1 LT 10] DO 1
  G1 X[#1 * 10] F500
  #1 = #1 + 1
END 1

              
Метки: N100. Циклы DO 1…3 / END 1…3, вложенность до 3 уровней. Счётчик обязательно менять внутри цикла, иначе бесконечный цикл. GOTO внутрь цикла запрещён.

Примеры параметрических программ

              

                

                  
1. Сетка отверстий

                  
O0001 (ПЛИТА 4x3)
G21 G90 G17
T1 M6
S2000 M3
G0 X0 Y0 Z5
G81 Z-6 R2 F150
#1 = 0                    (ряд)
WHILE [#1 LT 4] DO 1
  #2 = 0                  (колонка)
  WHILE [#2 LT 3] DO 2
    X[#2 * 20] Y[#1 * 15]
    #2 = #2 + 1
  END 2
  #1 = #1 + 1
END 1
G80
M5
M30

                

                

                  
2. Окружность фрезой

                  
O0002 (ОКРУЖНОСТЬ)
G21 G90
#1 = 25         (радиус)
#2 = 72         (точек)
#3 = 0          (угол)
#4 = 0          (счётчик)
G0 X#1 Y0 Z5
G1 Z-2 F200
WHILE [#4 LT #2] DO 1
  #3 = #3 + 360 / #2
  G1 X[#1 * COS[#3]] Y[#1 * SIN[#3]] F600
  #4 = #4 + 1
END 1
G0 Z5
M30

                

                

                  
3. Болтовое отверстие

                  
O0003 (6 ОТВЕРСТИЙ)
G21 G90 G17
#1 = 40         (радиус)
#2 = 6          (отверстий)
#3 = 0
S1500 M3
G81 Z-8 R2 F120
WHILE [#3 LT #2] DO 1
  #4 = 360 / #2 * #3
  X[#1 * COS[#4]] Y[#1 * SIN[#4]]
  #3 = #3 + 1
END 1
G80
M5
M30

                

                

                  
4. Косвенная адресация

                  
#1 = 100        (начальный номер)
#2 = 1          (значение)
WHILE [#1 LE 105] DO 1
  #[#1] = #2 * 2
  #1 = #1 + 1
  #2 = #2 + 1
END 1
( в #100…#105 записаны 2,4,6,8,10,12 )
G1 X#100 Y#101 F500

Резьбы, свёрла и режимы

              

            


            

              
Формулы, безопасность и совместимость

              

                

                  
Режимы резания

                  
    
                    
  • n = 1000 · Vc / (π · D) — обороты, об/мин
    • 
                    
  • F = n · fz · z — подача фрезы, мм/мин
    • 
                    
  • Vc — скорость резания, м/мин (алюминий ~250, сталь ~80, дерево ~400)
    • 
                    
  • fz — подача на зуб: 0,02·D для алюминия, 0,008·D для стали
    • 
                    
  • Шаг растра — 30–50 % от Ø фрезы
    • 
                  

                  
Резьба и сверление

                  
    
                    
  • Сверло под резьбу: d = D − P
    • 
                    
  • G84: F = P · S (мм/мин) или F = P при G95
    • 
                    
  • G83: Q — глубина захода, обычно 0,5–1 Ø
    • 
                    
  • G76: Q — смещение резца, P — пауза
    • 
                    
  • Наружная резьба: h = 0,6134 · P; траектория R = D/2 − h + Øфрезы/2
    • 
                    
  • Правая наружная — обход G2, левая — G3; проверьте направление на первом проходе
    • 
                  

                

                

                  
Безопасность

                  
    
                    
  • Z0 — поверхность заготовки, глубина реза отрицательная
    • 
                    
  • Безопасная Z — выше детали и струбцин, обычно 5–10 мм
    • 
                    
  • Лимит Z в валидаторе — ваша страховка от глубокого реза
    • 
                    
  • Всегда проверяйте программу в симуляторе станка
    • 
                  

                  
Совместимость макросов

                  
    
                    
  • Fanuc / Haas — Macro B: #, IF, WHILE, G65
    • 
                    
  • LinuxCNC — параметры #1 / #<имя>, свои O-подпрограммы и функции
    • 
                    
  • GRBL — макросов и переменных нет: только G-коды, параметризацию делайте в CAM
    • 
                    
  • Mach3 — макросы на VB, синтаксис Macro B не поддерживается полностью
    •
