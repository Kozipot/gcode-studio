# G-CODE STUDIO — универсальный генератор G-кода

Один автономный HTML-файл: **`gcode-universal.html`** (≈365 КиБ). Работает офлайн, без сервера и зависимостей: открыть двойным щелчком в браузере.

Семь вкладок: **Гравировка**, **Конструктор**, **Резьба / сверление**, **Импорт / проверка**, **Дуги G2/G3**, **Параметры**, **Шпаргалки**.

---

## Что нового

### 1. Многофигурный режим
Вкладка **«Конструктор»** — это мини-CAM: на одной заготовке собираются несколько элементов, каждый со своими параметрами, позицией, привязкой и поворотом. Порядок обработки — сверху вниз по списку.

Готовый пример по умолчанию: **рамка 66×38 + текст «G-CODE» + круг Ø12 по центру**. Шаблоны: рамка с надписью, шестигранная табличка, звезда, спираль, синусоида, карман с текстом, плита с отверстиями, обратная гравировка, **рельеф с разными высотами**.

### 2. Библиотека фигур
Прямоугольник, окружность, многоугольник (N сторон), звезда (N лучей), спираль, синусоида, паз, текст, **карман по контуру** (растровый съём внутри контура), **обратная гравировка** (съём вокруг контура), **сетка отверстий** с peck-сверлением.

Всё добавляется в общий список элементов и проходит через один и тот же конвейер траекторий (`moves`) — поэтому работает с любыми общими параметрами и постпроцессором.

### 3. Резьба, сверление, растачивание
Вкладка **«Резьба / сверление»** с тремя мини-вкладками:

| Цикл | Что считает |
|------|-------------|
| **G84** | резьба метчиком: диаметр, шаг, глубина, R, S, подача `F = P·S` (G94) или `F = P` (G95), жёсткая синхронизация M29 |
| **G83** | сверление с выводом стружки: peck `Q`, число заходов, S/F по материалу, варианты G73/G81/G82 |
| **G76** | тонкое растачивание: смещение `Q`, пауза `P`, подача |
| **Наружная** | фрезерование резьбы по внешнему диаметру: `D×P`, длина, Ø резьбовой фрезы, G2/G3, радиальные проходы |

Плюс таблица метрических резьб (M1.6–M24, G1/8", G1/4"), расчёт сверла под резьбу `d = D − P`, сетка отверстий. Каждый расчёт можно вставить в программу или превратить в полную программу с заголовком и M30.

### 4. Валидатор G-кода
Перед скачиванием программа проверяется по 17+ пунктам, чек-лист показывает зелёные галочки:

- есть `M30` / `M2`;
- шпиндель `M3/M4` с оборотами до реза;
- `G21`, `G90`, `G17`, `G94`;
- подача `F > 0` до первого реза;
- **рез не ниже лимита Z** (настраиваемое поле, по умолчанию −25 мм);
- **все координаты в пределах поля заготовки**;
- безопасная Z выше заготовки;
- нет быстрых ходов ниже Z0;
- корректность дуг (I/J или R, конец на окружности);
- `M5` перед `M30`;
- сбалансированные скобки комментариев;
- глубина за проход не больше 1,5 Ø инструмента;
- оценка времени и число строк.

При ошибке кнопка **«Скачать»** блокируется, пока проблема не исправлена. Тот же валидатор проверяет импортированный чужой G-код. Параметрические программы с `#переменными`, `WHILE`, `IF/THEN` и `GOTO` раскрываются для предпросмотра, расчёта времени и проверки. Полные круги `G3 I… J…` без `X/Y` тоже распознаются — внутренние кольца и спирали видны в превью.

### 5. Тултипы на каждом поле
У всех полей — значок `?`: наведение мышью или фокус с клавиатуры показывает объяснение (106 подсказок). Плюс блок «Быстрый старт» для новичков.

### 6. Кириллица в гравировке
Штриховой шрифт: **А–Я, Ё, Й**, латиница A–Z, цифры, `.,:;−+=/?!№`. Строчные автоматически становятся прописными. Если глифа нет — предупреждение в примечании и в чек-листе. Многострочный текст, выравнивание влево/центр/вправо.

### 7. Шпаргалки
Отдельная вкладка с быстрыми переходами по разделам:

- **Структура программы** — код и комментарии в две колонки, как в классических учебных примерах;
- **Переменные** — `#0`, `#1–#33`, `#100–#199`, `#500–#999`, системные, косвенная адресация;
- **Арифметика и функции** — `MOD`, `SIN/COS/TAN`, `ASIN/ACOS/ATAN`, `ABS`, `SQRT`, `ROUND/FIX/FUP`, `LN/EXP` с синтаксисом и примерами;
- **Сравнения и логика** — `EQ/NE/GT/LT/GE/LE`, `AND/OR/XOR`;
- **Переходы и циклы** — `IF … GOTO`, метки, `WHILE … DO/END`, вложенность;
- **G65** — полная таблица аргументов `A…#1`, `I…#4`, `X…#24`, `Z…#26` и пример макроса;
- **Системные переменные** — `#3000`, таймеры, дата/время, позиции осей;
- **Примеры** — сетка отверстий, окружность фрезой, болтовое отверстие, косвенная адресация;
- **G/M-коды**, **резьбы и режимы**, **формулы и совместимость** (Fanuc Macro B, LinuxCNC, GRBL, Mach3).

### 8. Калькулятор дуг — отдельная вкладка
Выбирается сверху: начало/конец дуги, R, G2/G3, расчёт центра, I/J, угла и длины, превью, кнопка **«Сбросить»** и вставка готового блока (с безопасным подъёмом, подачей и шпинделем) в текущую программу перед `M5`.
Есть режим **«Полный круг 360°»**: старт и конец совпадают, задаётся центр X/Y, а в G-код выводится `G3 X… Y… I… J…` — удобно для кругов, колец и спиралей из текущей точки.

### 9. Проект, отмена и правка кода
- **Undo/Redo** (`Ctrl+Z` / `Ctrl+Y`) и кнопки ↶/↷: отмена добавления, удаления, перемещения, параметров, массива, зеркала и выравнивания.
- **Автосохранение** сцены и параметров в `localStorage`: после перезагрузки проект восстанавливается автоматически.
- **G-код можно править вручную**: проверка и превью обновляются сами, ошибки видны в чек-листе, кнопка «Сгенерировать заново» возвращает код из параметров.
- Внизу страницы — ссылки на **GitHub** и **Issues** для сообщений о багах и предложений по доработкам.

### 10. Технологические возможности
- **Смещение контура** внутрь/наружу (поле «Смещение контура») — для вырезания детали в размер ставьте +радиус фрезы.
- **Перемычки (tabs)**: количество, ширина и высота мостиков; на глубине контур режется частями, оставляя материал.
- **Плавный вход**: рампа заданной длины вместо вертикального врезания для замкнутых контуров.
- **Массив, зеркало и выравнивание**: копии с шагом, зеркало ↔/↕ в карточке, выравнивание по краям/центру поля.
- **Оптимизация быстрых ходов**: порядок элементов и путей сортируется по ближайшей точке.

### 11. Расширенные проверки
К прежним 14 проверкам добавлены: быстрый ход сквозь заготовку, микросегменты, безопасность смены инструмента M6, разумность S/F, перемычки выше глубины, фреза не проходит в карман, дубликаты элементов. Технологические проверки сцены выводятся отдельными пунктами чек-листа.

### 12. Кастомный постпроцессор
- **WCS**: `G54…G59` или «не указывать».
- **Формат дуг**: `I/J` или `R` (с автоматическим знаком для дуг больше 180°).
- **Точность**: 0–4 знака после запятой.
- **M6 + G43 H…** в шапке с настраиваемым номером инструмента.
- **Шапка и подвал** с токенами `{TITLE}`, `{DATE}`, `{TIME}`, `{TOOL}`, `{S}`, `{F}`, `{SAFE_Z}`, `{BLANK}`, `{WCS}`.
- **%**, номера строк `N10…`, возврат `X0 Y0` — отдельными галочками.
- Всё это работает и для готовых пресетов (WCS/дуги/точность), а шапка/подвал/N-строки — в режиме **Custom**.

### 13. Библиотека инструментов и T/M6
- Инструменты `T1…Tn`: название, Ø, число зубьев, S, F, Fz.
- Каждому элементу сцены назначается свой инструмент.
- Операции группируются по инструменту; перед сменой выполняется `M5`, подъём на безопасную Z, `T… M6`, `G43 H…`, `M3 S…` с оборотами инструмента.
- Для карманов, смещения и обратной гравировки используется диаметр назначенного инструмента; оценка времени считается по фактическим подачам.
- Библиотека и флаг «использовать несколько инструментов» сохраняются в проекте.
- Для GRBL валидатор предупреждает, что `M6` не поддерживается.

### 14. Фигуры с разными высотами
- **Своя глубина у каждой фигуры**: в карточке элемента, блок «Высоты Z» → «Своя глубина». Пусто — берётся общая глубина программы.
- **Разные высоты внутри одной фигуры**: профили «Наклон по X», «Наклон по Y», «Ступени по X», «Ступени по Y».
  - наклон плавно меняет Z от `Z в начале` до `Z в конце`;
  - ступени делят фигуру на 2–64 плоские полосы, между ними Z меняется вертикально.
- Глубина режется с учётом «за проход»: для наклона/ступеней выполняется несколько проходов до целевого профиля.
- На карточке и в превью виден диапазон `Z`, в комментарии G-кода — фактическая высота элемента.
- Перемычки с профилем высоты несовместимы (генератор предупреждает); лимит Z и проверки сцены учитывают глубину каждого элемента.
- Шаблон **«Рельеф: разные высоты»** показывает три глубины и наклон на одной заготовке.

### 15. Калькулятор параметрического программирования
Отдельная вкладка **«Параметры»**:
- **Переменные** `#100…` с именами и выражениями; считаются сверху вниз, можно ссылаться на предыдущие.
- **Выражения Macro B**: `+ − * / ^ MOD`, `SIN/COS/TAN/ASIN/ACOS/ATAN`, `ABS/SQRT/ROUND/FIX/FUP/LN/EXP`, сравнения `EQ/NE/GT/LT/GE/LE`, логика `AND/OR/XOR`. Углы — в градусах, `ATAN[#1]/[#2]` учитывает квадрант.
- **Генераторы**: отверстия по окружности, сетка отверстий, рамка с проходами, окружность по точкам. Параметры задаются полями, код строится на `#переменных` и `WHILE`.
- **Две версии кода**: параметрическая (с `#` и циклами — для Fanuc/Haas/LinuxCNC) и числовая (готовые координаты). Числовая вставляется в основной G-код одной кнопкой и проходит чек-лист, поэтому её можно скачать.
- Подсказка по синтаксису и совместимости контроллеров — внизу вкладки.
- Параметрические шаблоны и переменные сохраняются в проекте и автосохранении.

### 16. Наружная резьба фрезой
Вкладка **«Резьба / сверление» → «Наружная резьба»**:
- выбор готовой метрической резьбы из таблицы или ручной ввод `D` и `P`;
- наружный диаметр `D`, шаг `P`, длина резьбы, Ø резьбовой фрезы;
- глубина профиля считается по формуле `h = 0,6134·P`;
- траектория — винтовая интерполяция `G2` (правая резьба) или `G3` (левая);
- несколько радиальных проходов от наружного диаметра к впадине;
- поддержка неполного последнего витка, если длина не кратна шагу;
- подсказки по режимам и предупреждения, если фреза/глубина/шаг не помещаются;
- расчёт и готовая программа с `M30`, проверка чек-листом.

Это именно **фрезерование** внешней резьбы резьбовой фрезой, а не плашка. Обычная концевая фреза оставит широкую канавку — нужен профильный резьбовой инструмент.

### 17. Трёхмерный предпросмотр
В панели предпросмотра есть переключатель **2D / 3D**:
- вращение мышью **без ограничения по вертикали** (можно смотреть сверху и снизу), зум колесом, панорамирование правой кнопкой или Shift;
- кнопка «Сброс вида»;
- ползунок **Масштаб Z** 1×–10×, чтобы видеть глубину резания;
- объёмная заготовка, оси X/Y/Z и сетка;
- рабочая подача окрашена по глубине, **быстрые ходы — голубым пунктиром**;
- работает для сцены, импортированных макросов и резьбы.

Это просмотр **траекторий** (wireframe), а не симуляция снятия материала. Полноценная 3D-симуляция с вырезанием металла — отдельная большая задача.

## Сохранено из исходника
- гравировка текста и чисел из выражения;
- обратная гравировка текста;
- калькулятор дуг G2/G3 с превью;
- импорт и предпросмотр G-кода;
- **калькулятор режимов резания** (материал, черновая/чистовая, Ø, зубья → S/F/Fz/ap/ae);
- постпроцессоры Universal / GRBL / Mach3 / LinuxCNC / Fanuc–Haas;
- СОЖ M8/M9, транслитерация комментариев для GRBL;
- оценка времени, длины реза и быстрых ходов;
- справочник G/M-кодов.

## Полезные детали
- **Z0** — поверхность заготовки, глубина реза отрицательная.
- **Карман/инверсия** используют диаметр инструмента и шаг растра (30–50 % Ø).
- **Обратная гравировка текста** оставляет буквы выпуклыми: снимается фон вокруг штрихов.
- Для **GRBL** комментарии автоматически транслитерируются в латиницу.
- Поля «Лимит Z», «Ø инструмента» и «Безопасная Z» управляют проверками безопасности.
- Все значения режимов ориентировочные: проверяйте программу в симуляторе станка.

## Разработка
Исходники разделены на модули, сборка склеивает их в один HTML:

```
src/data/glyphs.json   — штриховой шрифт (латиница, кириллица, знаки)
src/data/tables.json   — резьбы, материалы, режимы
src/styles.css         — тема интерфейса
src/body.html          — разметка
src/core.js            — чистое ядро: геометрия, траектории, G-код, валидатор, расчёты
src/ui.js              — DOM, вкладки, конструктор, чек-лист, превью
build.mjs              — сборка в gcode-universal.html
```

```bash
node build.mjs            # собрать единый HTML
node test/core.test.mjs   # 92 теста ядра (шрифт, фигуры, G-код, валидатор, высоты, параметрика, резьба)
node test/ui.test.mjs     # 161 UI-тест на linkedom (вкладки, конструктор, высоты, калькулятор, 3D, резьба)
node test/audit.mjs       # аудит сборки: id, ссылки, подсказки, автономность
node test/autosave.test.mjs # автосохранение и восстановление проекта
```

Тесты UI требуют `linkedom` (уже в devDependencies): `pnpm install`.
